# Computational Chemistry

A collection of projects and scripts spanning **molecular dynamics (MD)**, **quantum chemistry / DFT**, and **cheminformatics & machine learning**. This repo serves as a working portfolio of computational approaches to chemical problems — from simulating molecular systems to predicting properties with ML models.

## 🧪 Overview

| Area | Description | Common Tools |
|---|---|---|
| **Molecular Dynamics** | Simulating time-dependent behavior of molecular systems (conformational sampling, thermodynamics, binding) | GROMACS, OpenMM, MDAnalysis, LAMMPS |
| **DFT / Quantum Chemistry** | Electronic structure calculations — geometry optimization, energies, spectra, reactivity | PySCF, ORCA, Psi4, ASE |
| **Cheminformatics & ML** | Molecular representation, property prediction, QSAR/QSPR, generative models | RDKit, scikit-learn, PyTorch, DeepChem |

## 🔧 Key Dependencies

- **RDKit** — cheminformatics, molecular manipulation
- **PySCF** / **Psi4** — quantum chemistry calculations
- **ASE** (Atomic Simulation Environment) — structure building, MD interfaces
- **OpenMM** / **MDAnalysis** — molecular dynamics and trajectory analysis
- **NumPy, SciPy, pandas** — numerical computing and data handling
- **scikit-learn, PyTorch** — machine learning models
